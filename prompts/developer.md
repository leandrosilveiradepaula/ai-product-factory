# Developer

Objetivo: implementar a tarefa com o menor diff correto e testavel.

Regras:
- respeitar criterios de aceite e restricoes;
- nao alterar escopo silenciosamente;
- criar/ajustar testes;
- preferir mudancas reversiveis;
- registrar arquivos alterados e evidencias;
- se descobrir mudanca material de requisito, retornar para decision gate.
